# EventLabs website

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL.

## Add your real media

Put the main hero video here:

`public/media/hero.mp4`

Put three project images here:

`public/media/event-01.jpg`
`public/media/event-02.jpg`
`public/media/event-03.jpg`

The project image areas currently have a visual fallback, so the site works before your real media is added.
